# 비트코인 가격 방향 예측

머신러닝으로 비트코인의 다음 날 방향을 예측하고, 거래 비용을 반영해도
수익이 나는지 검증했습니다.

## 결과

| 지표 | 전략 | Buy & Hold |
|---|---|---|
| 연평균 수익 | +21.8% | +21.2% |
| 최대 낙폭 | **-9.7%** | -74.1% |
| 샤프 비율 | **1.46** | 0.39 |

수익은 비슷하지만 최대 낙폭이 7분의 1입니다.

## 전략

```
데이터  : 업비트 BTC 일봉 (2021-01 ~ 2026-08)
지표    : 온체인 6개 + 거래량 5개
모델    : SVC (RBF, C=2.0, gamma=0.02)
진입    : 예측 확률 > 0.5
          AND 종가 > MA30, MA200
          AND MA30 상승 중
청산    : 다음 날 종가
비용    : 왕복 0.10% (지정가 주문)
```

189회 거래, 승률 54.50% (손익분기 51.43%)

## 검증

| 방법 | 결과 |
|---|---|
| Walk-Forward 17폴드 (purge 적용) | 승률 54.50% |
| 앞뒤 hold-out | 55.17% vs 54.20% |
| 무작위 대조 2,000회 | **상위 0.5%** |
| 비용 민감도 | 왕복 0.10%까지 성립 |

같은 필터 구간에서 아무 날이나 거래하면 평균 +29.5%인데, 모델이 고른 날은
+128.2%였습니다. **필터가 아니라 모델이 기여했음을 보여줍니다.**

## 주요 발견

**널리 쓰이는 지표일수록 성적이 나빴습니다.**

| 지표 그룹 | 누적 수익 |
|---|---|
| 온체인 + 거래량 | +64.7% |
| 변동성 | +24.3% |
| 모멘텀 (RSI, 스토캐스틱) | -54.5% |
| 추세 (MACD, ADX) | -83.8% |

**복잡한 모델이 더 나빴습니다.** SVC +64.7%, LSTM -54.8%, 베이지안 신경망
-78.9%. 표본 1,959일에는 신경망이 과했습니다.

**모델은 자기 확신도를 몰랐습니다.** 베이지안 신경망에서 예측 불확실성이
낮은 구간의 정확도가 오히려 가장 낮았습니다(45.69% vs 47.00%).

**예측보다 언제 하느냐가 중요했습니다.** 거래를 567회에서 189회로 줄이자
승률이 50.62%에서 54.50%로 올랐습니다.

## 한계

- **비용 여유 없음** — 왕복 0.10%가 상한, 업비트 수수료가 정확히 그 값
- **하락장 무수익** — 2025년 +1.6%, 손실을 막을 뿐
- **ETH 재현 실패** — 온체인이 BTC 네트워크 데이터라 애초에 부적절한 적용
- **표본 5년 반** — 이 기간에 없던 국면은 검증 불가

## 실행

```bash
pip install pyupbit pandas numpy scikit-learn lightgbm torch matplotlib pyarrow
```

`pyupbit`로 KRW-BTC 일봉을 받아 `data/clean/KRW-BTC_1d.parquet`으로
저장한 뒤 노트북을 실행합니다. 수집 시 **아직 마감되지 않은 마지막 봉은
제거**해야 합니다(업비트 일봉은 09시 마감).

온체인 데이터는 노트북 안에서 blockchain.com API로 자동 수집되며 키가
필요 없습니다.
